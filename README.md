# My-Lessonsy-Website

Site de présentation de cours et d’activités. Les pages détaillent les services de musique, de sport et d’arts.

[Catalogue des cours](https://baalla-my-lessonsy-demo.abdelhakimbaalla50.workers.dev) · [Catalogue des activités](https://github.com/Abdelhakim-Baalla/My-Lessonsy-Website/blob/main/Html/service.html)

Pour reconstruire la démo depuis la racine du dépôt, exécuter `python3 scripts/build-demo.py`. À la racine, `npx wrangler deploy` publie les fichiers générés.
